# Wolo web URL modes

## Single-location Wolo Code links

```text
https://wolo.codes/<reference>.<word1>.<word2>.<word3><suffix>[?zoom=<level>]
```

The last three dot-separated tokens are Wolo dictionary words. The preceding tokens identify the city or indexed region. A city can include geographic qualifiers to disambiguate it, as in `india.karnataka.bangalore-division.vittasandra.live.muffin.pen`. An indexed region includes its number, as in `usa-40.tub.plate.chain`.

Use lowercase and hyphens for spaces within a token. The web app also accepts uppercase letters, internal underscores, plus signs, and percent-encoded spaces in existing links. For example, `USA_40.TUB.PLATE.CHAIN` resolves to the same location as `usa-40.tub.plate.chain`.

| Mode | Example | What opens |
| --- | --- | --- |
| Standard preview | `/usa-40.tub.plate.chain` | Wolo shows the code and address preview. **Go** opens the external map. Close the preview to use the location in Wolo. |
| Satellite preview | `/usa-40.tub.plate.chain_` | Wolo requests its satellite layer at startup and shows the same code and address preview. |
| External map redirect | `/usa-40.tub.plate.chain/` | Wolo shows the preview and names the destination. The top progress bar counts down three seconds once the code resolves, then the external map opens automatically. **Stop** cancels the redirect and opens the location in Wolo. |

A suffix comes immediately after the last word, before any query string. The underscore inside a legacy reference such as `usa_40` is a space separator. An underscore after the last word selects satellite mode.

### Zoom

`?zoom=16` requests the zoom level used when Wolo displays the decoded location. Wolo caps the requested zoom at the active map layer’s maximum. A missing or invalid value defaults to two levels below that maximum. Standard links copied from the map include the current zoom when available. A jump link generated by Wolo carries the trailing slash.

### External map preference

**External map** in the account and sign-in settings applies to both **Go** and automatic redirects. The browser remembers the choice locally.

| Setting | Destination |
| --- | --- |
| Automatic | Android sends the location to the device’s geo handler. iPhone, iPad, and iPod use Apple Maps. Other devices use Google Maps. |
| Google Maps | Opens a Google Maps link. |
| Apple Maps | Opens an Apple Maps link. |

When you press **Stop**, Wolo removes the trailing slash from the current URL and preserves its query string and fragment. The resolved location stays in Wolo, including when you stop before the code has finished decoding.

## Root URL modes

| Mode | Example | What opens |
| --- | --- | --- |
| Home | `/` | Wolo’s normal startup view. |
| Coordinate lookup | `/?q=25.996772,-97.157990` | Wolo opens the point and starts encoding it as a Wolo Code. Use decimal latitude followed by longitude. |
| Wolo Code route | `/?from=usa-40.tub.plate.chain&to=north-pacific-13165.tunnel.dark.mail` | Wolo resolves the codes, restores the ordered markers, and fits them in view. |
| Coordinate route | `/?from=12.97,77.59&via=13.08,80.27&to=17.38,78.49` | Wolo restores the ordered markers from decimal latitude–longitude pairs and fits them in view. |

Route links require both `from` and `to`. Repeat `via` for each intermediate stop in travel order. Each stop can be a dot-separated Wolo Code or a coordinate pair. Use the code alone in a route parameter, without the host, leading slash, mode suffix, or zoom query. A comma can also be URL-encoded as `%2C`. Coordinate route stops accept latitudes from −90 to 90 and longitudes from −180 to 180.

In Map View, tap **Route** to share Wolo Codes or hold **Route** to share coordinates. A route link restores the stops in Wolo so you can inspect them and choose **Directions**.
